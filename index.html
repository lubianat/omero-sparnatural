This is an IDR Sparnatural demo and prototype developed as part of the foundingGIDE project. It explores advanced metadata search for the Image Data Resource (IDR), using RO-Crate to convert study metadata into JSON-LD/RDF.

Extended rationale and background are available at BioImage-Archive/gide-search.
